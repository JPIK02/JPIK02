## Les autres tâches (agent mail, coach, réservations, ajoutées à la main)

Leur étape ne change pas. Leur thème suit ces règles, dans l'ordre :
1. Tâche de réservation : acompte et solde → L'argent ; contrat et point un mois avant → Les prestataires.
2. Mots du titre : budget, payer, acompte, solde → L'argent ; mairie, notaire, bans, papiers → Mairie et papiers ; invités, plan de table, hébergement → Les invités ; faire-part, papeterie, save-the-date → Faire-part et papeterie ; robe, costume, tenue, alliance, coiffure, maquillage, essayage → Tenues et beauté ; lieu, salle, domaine, château → Le lieu ; cérémonie, officiant, discours → La cérémonie ; traiteur, photographe, vidéaste, DJ, musique, fleuriste, prestataire → Les prestataires.
3. Reliée à un prestataire → Les prestataires (Le lieu pour un lieu).
4. Sinon → Logistique.

Le thème de chaque tâche reste modifiable sur la page de la tâche.
